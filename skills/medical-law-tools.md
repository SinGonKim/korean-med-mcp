# Medical Law Tool

의료 관련 법령, 판례, 행정심판례를 검색할 때 사용한다.

## `search_medical_law`

법제처 공개 API로 의료 관련 법령, 판례, 행정심판례를 검색한다.

## 적합한 요청

- "응급실 진료 거부는 불법이야?"
- "의료법 제15조 찾아줘"
- "비급여 고지 관련 법령 알려줘"
- "의료과오 판례 검색해줘"
- "의사 면허 취소 행정심판례 찾아줘"

## 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `query` | string | 예 | 검색어. 예: `응급실 진료거부`, `의료과오`, `비급여`, `의사 면허 취소` |
| `lawName` | enum | 아니오 | 특정 법령 내 검색. 지원 법령은 아래 목록 참조 |
| `articleNo` | string | 아니오 | 특정 조문 조회. 예: `제15조`, `제48조의2` |
| `searchType` | enum | 아니오 | `law`, `precedent`, `admin_appeal`. 기본값 `law` |
| `display` | number | 아니오 | 1-20, 기본값 `5` |

## 지원 법령

- `의료법`
- `응급의료에 관한 법률`
- `약사법`
- `국민건강보험법`
- `감염병의 예방 및 관리에 관한 법률`
- `의료사고 피해구제 및 의료분쟁 조정 등에 관한 법률`

## 사용 예

법령 검색:

```json
{
  "query": "응급실 진료거부",
  "searchType": "law",
  "display": 5
}
```

특정 법령의 특정 조문 조회:

```json
{
  "query": "진료 거부",
  "lawName": "의료법",
  "articleNo": "제15조",
  "searchType": "law"
}
```

판례 검색:

```json
{
  "query": "의료과오",
  "searchType": "precedent",
  "display": 10
}
```

행정심판례 검색:

```json
{
  "query": "의사 면허 취소",
  "searchType": "admin_appeal",
  "display": 5
}
```

## 결과 해석

`law` 검색 결과에는 법령명, 법령 유형, 시행일, law.go.kr 원문 링크가 포함된다. `articleNo`가 있으면 해당 조문 본문 조회를 시도한다.

`precedent` 검색 결과에는 법원, 사건번호, 선고일, 사건명, 판시사항 요약, 참조조문, 원문 링크가 포함될 수 있다.

`admin_appeal` 검색 결과에는 사건번호, 결정일, 기관, 요지, 결과가 포함될 수 있다.

## 답변 원칙

- 법령·판례 결과를 설명할 때 "법률 자문이 아니라 공개 법령 데이터 조회 결과"임을 밝힌다.
- 사용자의 상황에 곧바로 위법·합법 결론을 단정하지 않는다. 조문과 판례의 요지를 구분해 설명한다.
- 실제 분쟁, 신고, 소송, 행정처분 대응은 변호사, 보건소, 관계기관 상담을 권한다.
- 특정 조문 전문이 필요하면 `articleNo`를 사용한다.
