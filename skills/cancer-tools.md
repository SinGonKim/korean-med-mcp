# Cancer Information Tools

국가암정보센터 API로 암 종류별 정보, 예방·검진, FAQ, 용어사전, 통계, 생활 가이드를 조회할 때 사용한다.

## 공통 주의

- 암 정보는 진단이나 치료 계획을 대체하지 않는다.
- 증상이나 검사 결과를 바탕으로 암 여부를 단정하지 않는다.
- 치료 선택, 항암제, 수술, 방사선치료, 부작용 관리는 담당 의료진 상담을 우선 안내한다.
- 암 정보 tool은 `DATA_GO_KR_API_KEY`를 사용하지만 README 기준 별도 활용신청 없이 사용할 수 있다.

## `search_cancer_info`

암 종류별 개요, 원인, 증상, 진단, 치료 정보를 검색한다.

### 적합한 요청

- "갑상선암 증상이 뭐야?"
- "폐암 원인 알려줘"
- "위암 치료 방법 찾아줘"
- "암 종류 목록 보여줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `cancerType` | string | 아니오 | 암 종류. 예: `갑상선암`, `폐암`, `위암`. 미입력 시 전체 목록 |

### 사용 예

```json
{
  "cancerType": "갑상선암"
}
```

## `get_cancer_prevention`

암 예방법과 국가암검진 안내를 조회한다.

### 적합한 요청

- "위암 예방하려면 어떻게 해야 해?"
- "국가암검진 기준 알려줘"
- "금연이 암 예방에 어떤 영향이 있어?"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `topic` | string | 아니오 | 예방·검진 주제. 예: `금연`, `음식`, `운동`, `검진` |

### 사용 예

```json
{
  "topic": "국가암검진"
}
```

## `search_cancer_faq`

국가암정보센터의 암 관련 FAQ를 검색한다.

### 적합한 요청

- "항암치료 부작용 FAQ 찾아줘"
- "금연 관련 암 FAQ"
- "암환자 식이요법 자주 묻는 질문"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `query` | string | 아니오 | 질문 키워드. 예: `금연`, `항암치료` |
| `category` | string | 아니오 | 카테고리 필터. 예: `금연`, `식이요법` |

### 사용 예

```json
{
  "query": "항암치료",
  "category": "식이요법"
}
```

## `search_cancer_dictionary`

암 관련 의학 용어 사전을 검색한다.

### 적합한 요청

- "면역항암제가 뭐야?"
- "전이 뜻 알려줘"
- "항암제 용어 설명해줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `term` | string | 예 | 암 관련 용어. 예: `항암제`, `면역항암`, `전이` |

### 사용 예

```json
{
  "term": "면역항암"
}
```

## `get_cancer_statistics`

국가 암 발생률, 생존율, 사망률 등 통계 정보를 조회한다.

### 적합한 요청

- "한국 암 발생률 알려줘"
- "암 생존율 통계 찾아줘"
- "암 사망률 자료 보여줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `topic` | string | 아니오 | 통계 주제. 예: `발생률`, `생존율`, `사망률` |

### 사용 예

```json
{
  "topic": "생존율"
}
```

## `get_cancer_life_guide`

암환자 생활백서 정보를 조회한다.

### 적합한 요청

- "암 생존자 식단 관리법 알려줘"
- "암환자 운동 가이드 찾아줘"
- "항암치료 중 정서 관리 방법"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `topic` | string | 아니오 | 생활 가이드 주제. 예: `암생존자`, `영양`, `운동`, `정서` |

### 사용 예

```json
{
  "topic": "영양"
}
```

## 결과 해석

대부분의 암 정보 tool은 제목, 경로, 요약 내용, 링크를 반환한다. 상세 본문이 축약될 수 있으므로 사용자가 더 깊은 정보를 원하면 반환된 링크 또는 더 구체적인 키워드로 다시 조회한다.
