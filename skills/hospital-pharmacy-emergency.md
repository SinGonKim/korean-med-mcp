# Hospital, Pharmacy, and Emergency Tools

병원·약국·응급실 관련 사용자의 위치성 질문과 기관 검색 질문을 처리할 때 사용한다.

## `find_hospital`

병원명 또는 지역명 키워드로 전국 병원·의원·종합병원을 검색한다.

### 적합한 요청

- "강남세브란스 전화번호 알려줘"
- "서울 강남 정형외과 찾아줘"
- "근처 상급종합병원 검색해줘"
- "삼성서울병원 주소가 뭐야?"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `keyword` | string | 예 | 병원명 또는 지역명. 예: `강남세브란스`, `삼성서울병원`, `강남 정형외과` |
| `hospitalType` | string | 아니오 | 종별코드. `01` 상급종합, `11` 종합병원, `21` 병원, `28` 요양병원, `29` 정신병원, `31` 의원, `41` 치과병원, `51` 치과의원 |
| `pageNo` | number | 아니오 | 기본값 `1` |
| `numOfRows` | number | 아니오 | 1-20, 기본값 `10` |

### 사용 예

```json
{
  "keyword": "강남세브란스",
  "hospitalType": "01",
  "numOfRows": 5
}
```

### 결과 해석

결과에는 기관명, 종별, 주소, 전화번호, 총 의사 수, 홈페이지가 포함될 수 있다. 진료과, 운영시간, 예약 가능 여부는 이 tool만으로 보장하지 않는다.

## `find_pharmacy`

약국명 또는 지역명 키워드로 전국 약국을 검색한다.

### 적합한 요청

- "역삼동 약국 찾아줘"
- "강남약국 전화번호 알려줘"
- "서울 강남구 약국 목록 보여줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `keyword` | string | 예 | 약국명 또는 지역명. 예: `강남약국`, `강남`, `역삼동` |
| `pageNo` | number | 아니오 | 기본값 `1` |
| `numOfRows` | number | 아니오 | 1-20, 기본값 `10` |

### 사용 예

```json
{
  "keyword": "역삼동",
  "numOfRows": 10
}
```

### 결과 해석

결과에는 약국명, 주소, 전화번호, 시도/시군구 정보가 포함된다. 야간·휴일 운영 여부는 별도 확인이 필요하다.

## `get_er_status`

응급실 실시간 가용 병상 현황을 조회한다. 실시간성 때문에 캐시는 2분이다.

### 적합한 요청

- "지금 서울 응급실 자리 있어?"
- "부산 응급실 병상 현황 알려줘"
- "전국 응급실 가용 병상 몇 개야?"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `region` | string | 아니오 | 지역 필터. 예: `서울`, `경기`, `부산`. 미입력 시 전국 |
| `numOfRows` | number | 아니오 | 1-50, 기본값 `20` |

### 사용 예

```json
{
  "region": "서울",
  "numOfRows": 20
}
```

### 결과 해석

결과에는 병원명, 주소, 대표전화, 응급실 직통 전화, 가용 일반 병상, 가용 중환자 병상, 업데이트 시각이 포함될 수 있다.

응급실 병상 수는 이동 중에도 바뀔 수 있다. 응답에는 반드시 전화 확인 필요성을 덧붙인다.

| `get_er_status` | 국립중앙의료원 응급의료정보제공 | `DATA_GO_KR_API_KEY` | 필요 |
