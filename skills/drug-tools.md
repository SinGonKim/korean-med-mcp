# Drug and Prescription Statistics Tools

의약품 허가정보, 알약 식별, 특허, 처방·조제 사용량 통계 질문에 사용한다.

## 공통 주의

- 의약품 정보는 복약 지도나 처방을 대체하지 않는다.
- 복용량 변경, 병용 가능성, 임신·수유 중 복용, 부작용 발생 시 대처는 의사나 약사 상담을 우선 안내한다.
- 제품명 검색과 성분명 검색은 다르다. 허가정보는 제품명, 특허와 사용량 통계는 주로 성분명 기반으로 요청한다.

## `search_drug`

의약품명으로 허가정보를 조회한다.

### 적합한 요청

- "타이레놀 효능 알려줘"
- "이부프로펜 주의사항이 뭐야?"
- "아스피린 주성분과 용법 알려줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `drugName` | string | 예 | 의약품명. 예: `타이레놀`, `아스피린`, `이부프로펜` |
| `pageNo` | number | 아니오 | 기본값 `1` |
| `numOfRows` | number | 아니오 | 1-5, 기본값 `3` |

### 사용 예

```json
{
  "drugName": "타이레놀",
  "numOfRows": 3
}
```

### 결과 해석

제품명, 업체명, 전문/일반 구분, 주성분, 보관방법, 효능·효과, 용법·용량, 주의사항이 포함될 수 있다.

## `identify_pill`

알 수 없는 알약을 모양, 색상, 각인, 제형으로 식별한다. `shape`, `color`, `imprint` 중 하나 이상은 필요하다.

### 적합한 요청

- "흰색 타원형 ER 각인 약 찾아줘"
- "분홍색 원형 알약이 뭔지 알고 싶어"
- "앞면 524라고 적힌 캡슐 찾아줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `shape` | string | 조건부 | 모양. 예: `원형`, `타원형`, `장방형`, `삼각형`, `사각형`, `기타` |
| `color` | string | 조건부 | 색상. 예: `흰색`, `노란색`, `분홍색` |
| `imprint` | string | 조건부 | 각인 문자 또는 숫자. 예: `ER`, `524` |
| `formulation` | string | 아니오 | 제형. 예: `정제`, `캡슐제`, `필름코팅정` |

### 사용 예

```json
{
  "shape": "타원형",
  "color": "흰색",
  "imprint": "ER"
}
```

### 결과 해석

제품명, 업체명, 모양, 색상, 앞면/뒷면 각인, 제형, 분류가 포함된다. 여러 후보가 나올 수 있으므로 식별 결과만으로 복용을 권하지 않는다.

## `search_drug_patent`

의약품 성분명으로 국내 의약품 특허정보를 조회한다.

### 적합한 요청

- "아세트아미노펜 특허정보 찾아줘"
- "암로디핀 특허 만료일 알려줘"
- "이부프로펜 의약품 특허권자 조회해줘"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `ingrName` | string | 예 | 성분명. 예: `아세트아미노펜`, `이부프로펜`, `암로디핀` |
| `pageNo` | number | 아니오 | 기본값 `1` |
| `numOfRows` | number | 아니오 | 1-10, 기본값 `5` |

### 사용 예

```json
{
  "ingrName": "아세트아미노펜",
  "numOfRows": 5
}
```

### 결과 해석

제품명, 업체명, 성분명, 특허구분, 발명명칭, 특허권자, 특허번호, 특허 상태, 만료일이 포함될 수 있다.

## `get_drug_usage_by_area`

특정 진료년월의 의약품 성분별 지역별 사용량·금액 통계를 조회한다.

### 적합한 요청

- "2025년 1월 메트포르민 지역별 처방량 알려줘"
- "202501 서울 지역 의약품 사용량 통계"
- "아세트아미노펜 지역별 사용금액 조회"

### 입력

| 필드 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `diagYm` | string | 예 | 진료년월 `YYYYMM`. 보통 6개월 이상 전 데이터부터 제공 |
| `ingrName` | string | 아니오 | 성분명 키워드. 미입력 시 전체 결과에서 조회 |
| `insupTp` | enum | 아니오 | `0` 전체, `4` 건강보험, `5` 의료급여, `7` 보훈. 기본값 `4` |
| `cpmdPrscTp` | enum | 아니오 | `01` 조제기준, `02` 처방기준. 기본값 `02` |
| `pageNo` | number | 아니오 | 기본값 `1` |
| `numOfRows` | number | 아니오 | 1-20, 기본값 `10` |

### 사용 예

```json
{
  "diagYm": "202501",
  "ingrName": "메트포르민",
  "insupTp": "4",
  "cpmdPrscTp": "02"
}
```

## `get_drug_usage_by_disease`

특정 진료년월의 의약품 성분별 상병별 사용량·금액 통계를 조회한다.

### 적합한 요청

- "202501 아세트아미노펜이 어떤 질환에 많이 쓰였는지 알려줘"
- "당뇨 관련 메트포르민 사용량 통계 찾아줘"
- "상병별 처방금액 조회"

### 입력

`get_drug_usage_by_area`와 동일하다. 결과에는 상병명, 상병코드, 사용량, 금액이 포함될 수 있다.
